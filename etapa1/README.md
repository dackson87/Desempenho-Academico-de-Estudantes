# Etapa 1 – Análise Exploratória de Dados (EDA)

Esta etapa tem como objetivo compreender o dataset, identificar padrões, verificar inconsistências e levantar hipóteses que irão orientar as próximas fases do projeto.

## Arquivo Principal
- **01_EDA.ipynb**

## Conteúdo da Etapa
- Leitura e compreensão inicial do dataset
- Verificação de tipos, quantidades e estrutura das colunas
- Estatísticas descritivas (`describe()`)
- Análise de missing values
- Visualização de distribuições (histogramas)
- Identificação de possíveis outliers
- Análise de correlação entre variáveis
- Insights iniciais que orientam o pré-processamento
